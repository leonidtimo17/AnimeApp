# AnimeApp

Приложение для просмотра аниме со своим плеером и локальной библиотекой — для **Windows** и **Android-планшетов**
(в том числе Huawei на HarmonyOS 2–4 / EMUI). Всё бесплатно, без ключей и регистрации.

## Установка

Скачайте файл со страницы [Releases](../../releases/latest):

| Устройство | Файл | Как поставить |
|---|---|---|
| Windows 10/11 (64-бит) | `AnimeApp-Setup-*.exe` | Запустите и нажмите «Далее». Права администратора не нужны. Если SmartScreen пишет «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае» (у установщика нет платной цифровой подписи). |
| Планшет/телефон Android, Huawei (HarmonyOS 2–4, EMUI) | `AnimeApp-*.apk` | Скачайте APK на планшет и откройте. Разрешите установку из этого источника: «Настройки → Безопасность → Дополнительные настройки → Установка приложений из внешних источников» (на Huawei может называться «Неизвестные источники»). |

На Huawei с HarmonyOS 3–4 может быть включён **«Чистый режим»** — он блокирует установку APK не из AppGallery. Отключите его: «Настройки → Система и обновления → Чистый режим → Выход», установите приложение и при желании включите режим обратно.

HarmonyOS NEXT (5.x) Android-приложения не поддерживает.

Списки, история и прогресс хранятся на самом устройстве (у ПК и планшета — свои).

## Источники

| Источник | Что даёт | Как играет |
|---|---|---|
| **AniLibria** | каталог, расписание, озвучка AniLibria, таймкоды опенинга/эндинга | встроенный плеер (HLS до 1080p) |
| **AnimeVost** | озвучка AnimeVost | встроенный плеер (mp4 720p/480p) |
| **AnimeLib → Kodik** | десятки озвучек и субтитров | плеер Kodik внутри приложения (на ПК — WebView2), прогресс синхронизируется |
| **YummyAnime → Kodik** | озвучки тайтлов, которых нет в AnimeLib (лицензионные: «Тетрадь смерти», фильмы Гибли…), время заставки | плеер Kodik внутри приложения |
| **Shikimori** | полный каталог всех аниме, сезоны и фильмы франшизы, даты выхода серий | — |
| **AniSkip** | время опенинга и эндинга, размеченное сообществом, — если источник его не дал | кнопка «Пропустить заставку», автопропуск |

Озвучка выбирается на странице тайтла (кнопка с микрофоном над списком серий).
Выбор запоминается для тайтла, а последняя выбранная озвучка становится любимой и подставляется автоматически.
Прогресс хранится по номеру серии, поэтому при смене озвучки продолжаете с того же места.

### Страница просмотра как на YouTube
Видео не на весь экран: под ним название, серия, кнопки (озвучка, «Избранное», «Хочу посмотреть», сезоны,
«На весь экран»), описание и обсуждение серии; справа — список серий с кадрами и вкладки «Все серии / Непросмотренные».
Полный экран — кнопкой, клавишей F или двойным кликом. На планшете в книжной ориентации всё в одну колонку, видео сверху.

### Фишки просмотра
- **Пропуск заставки и титров** по точной разметке (AniLibria, YummyAnime или AniSkip), автопропуск в настройках плеера.
- **Таймер сна** (кнопка с луной): остановить через 15–90 минут или после текущей серии.
- **Скорость 2x, пока держите** палец на видео (планшет) или кнопку мыши (ПК).
- **Масштаб «весь кадр / заполнить экран»** — без чёрных полос (кнопка, клавиша Z на ПК, жест двумя пальцами на планшете).
- **Серии с кадрами** на странице тайтла и в списке серий плеера.

### Shikimori: статистика и обсуждения
- **Вход через Shikimori** (по желанию): «Моя библиотека» → «Войти через Shikimori» (на планшете — раздел «Моё»).
  Приложение отмечает в вашем списке на Shikimori просмотренные серии, статусы и оценки — там строится статистика.
  Можно отправить весь список разом или загрузить свой список с Shikimori.
- **Обсуждение серии прямо в плеере** (кнопка с облачками, клавиша C): комментарии Shikimori к этой серии или ко всему
  аниме. Можно написать свой — с отметкой момента серии (время в комментариях кликабельно — перематывает видео)
  и под спойлером. Читать может каждый, писать — после входа.

Для входа нужно OAuth-приложение Shikimori: https://shikimori.io/oauth/applications → «Новое приложение»,
Redirect URI `urn:ietf:wg:oauth:2.0:oob`, права `user_rates` и `comments`. Его Client ID и Client Secret впишите в
`anime_app/shiki_config.py` и `mobile/www/js/shiki_config.js` (шаблоны — `*.example.*`; эти файлы не хранятся в git).

Окно Kodik — это их штатный встраиваемый плеер: в нём бывает реклама, а «пропустить заставку»
работает как перемотка на +85 с (точных таймкодов у Kodik нет).

## Запуск
Двойной клик по `run.bat` (при первом запуске сам поставит зависимости).
Отдельный `.exe` без Python: `build.bat` → `dist\AnimeApp\AnimeApp.exe`.

## Возможности
- Главная: «Продолжить просмотр», «Выходит сегодня», новые серии, популярное, «Хочу посмотреть».
- Поиск по названию + фильтры: жанр, тип, годы, сортировка; бесконечная прокрутка.
- Расписание выхода серий на неделю.
- Страница тайтла: рейтинги Shikimori/MAL, описание, жанры, серии с прогрессом, связанные релизы.
- Библиотека: Смотрю / Хочу посмотреть / Просмотрено / Отложено / Брошено / Избранное, личная оценка,
  статистика, экспорт/импорт резервной копии.
- Сезоны и фильмы: лента франшизы (сезоны, фильмы, OVA, спешлы, анонсы) по данным Shikimori —
  клик открывает нужный сезон или фильм, даже если его нет на AniLibria.
- Все серии тайтла из всех источников: если в выбранной озвучке серии нет, она показана пунктиром
  («есть в: AnimeVost, Kodik»), а клик сам включит озвучку, где она есть.
- Предстоящие серии с датами: выход в Японии (Shikimori) и примерная дата озвучки (по дню выхода у AniLibria).
- Плеер открывается внутри окна приложения (и встроенный, и Kodik); кнопка «мини-плеер» — маленькое окно поверх всех.
- Каталог: фильтры по жанрам (можно несколько — ищутся тайтлы со всеми сразу), типу, статусу
  (выходит / вышло), сезону года и годам + сортировка. Фильтры запоминаются.
- «Для вас»: анализ вкуса по вашим спискам, оценкам и просмотренным сериям — любимые жанры,
  формат, эпоха; рекомендации с процентом совпадения и причиной, подборки «Потому что вам понравилось…».
  Кнопка «ИИ-разбор вкуса» — текстовый разбор и подборка от ИИ: локальная Ollama, если установлена
  (приватно, офлайн), иначе бесплатный Pollinations без ключа. ИИ получает только названия, жанры и годы.
- В плеере: выбор сезона/фильма франшизы и смена озвучки с той же серии и того же места.
- Поиск по полному каталогу Shikimori: находятся все аниме, даже которых нет на AniLibria
  (серии для них ищутся в AnimeVost и AnimeLib).
- Качество «Авто»: скорость интернета измеряется **один раз при запуске приложения** — на кусочке свежей серии
  AniLibria, когда главная загрузилась, — и по ней выбирается качество (в меню помечено «рекомендовано»).
  Во время просмотра приложение скорость не меряет: поток HLS сам подстраивает качество по тому, как грузится видео,
  а если видео часто подгружается — качество понижается. Проверить скорость заново — «Качество → Проверить скорость
  интернета». Можно выбрать качество вручную — выбор запоминается.
- В меню качества только те варианты, что реально есть у серии, с настоящим разрешением
  (например, у старых релизов «480p» на деле 360p — так и будет подписано). На странице тайтла видно «до 1080p».
  Потоков 4K ни у одного из бесплатных источников сейчас нет (максимум — 1080p у AniLibria);
  если появятся, приложение подпишет их как «4K».
- Кэш: постеры (до 500 МБ на диске на ПК), ответы серверов (SQLite на ПК, IndexedDB на планшете; со сроками
  свежести; без интернета показывается последнее сохранённое), данные тайтлов из библиотеки. «Библиотека → Резервная
  копия → Очистить кэш» (на планшете — «Моё → Очистить кэш») — очистить.
- История просмотра.
- На любой карточке при наведении — кнопки «в избранное» и «хочу посмотреть»,
  по правому клику — меню со всеми списками.

## Языки
Русский, саха и английский. ПК — кнопка «Язык» внизу меню, планшет — «Библиотека → Настройки». Язык меняется сразу,
без перезапуска, и запоминается. Перевод на саха пока неполный: чего нет, показывается по-русски. Если вы говорите
по-саха и хотите помочь — список фраз, ждущих перевода: `python -m anime_app.core.i18n sah`.

## Плеер
- Продолжение с места остановки: прогресс сохраняется во время просмотра (раз в 5 с), на паузе, при смене серии и закрытии.
- Понятные состояния «Загрузка…» и «Подгрузка…»; при сбое — «Не удалось загрузить видео» и кнопка «Повторить».
- «Пропустить заставку» (и автопропуск) по таймкодам опенинга.
- «Следующая серия через 10…» на титрах, автопереход.
- Качество 1080/720/480 без потери позиции, скорость 0.5–2x, громкость запоминается.
- Список серий в плеере, полный экран, «картинка в картинке» (окно поверх всех).
- Отметки опенинга/эндинга на полосе перемотки, превью времени при наведении.
- Серии автоматически отмечаются просмотренными, тайтл — «Смотрю» / «Просмотрено».

| Клавиша | Действие |
|---|---|
| Пробел / K | пауза |
| ← / → (Shift — 30 с) | перемотка 10 с |
| ↑ / ↓, колесо мыши | громкость |
| F, двойной клик | полный экран |
| M | звук |
| N / P | следующая / предыдущая серия |
| S | пропустить заставку |
| E | список серий |
| I | картинка в картинке |
| [ / ] | скорость |
| 0–9 | перейти на 0–90 % |
| Esc | выход из полноэкранного / закрыть |

## Архитектура и разработка

Код разделён на слои: `core` (общее) → `domain` (правила приложения) → `application` (сценарии) →
`infrastructure` (сеть, API, база) → `presentation` (интерфейс). Подробно — в [ARCHITECTURE.md](ARCHITECTURE.md):
структура проекта, поток данных, сеть и кэш, состояние, плеер, как добавить экран или компонент.

```
anime_app/            ПК-версия (Python, PySide6)
  core/               ошибки, кэш LRU+TTL, адреса и сроки кэша, журнал, форматирование
  domain/             чистые правила: названия, серии, озвучки, качество, франшизы, рекомендации, таймер сна
  application/        сервисы: библиотека и прогресс, карточки, источники, плеер, поиск, Shikimori, резервные копии
  infrastructure/     HttpClient, API (AniLibria, Shikimori, AnimeLib, AnimeVost, YummyAnime, AniSkip, ИИ),
                      SQLite (репозитории), картинки, NetworkService (состояние сети, один замер скорости)
  presentation/       окно, страницы, виджеты, плеер
  app.py              сборка приложения
mobile/www/js/        планшетная версия (ES-модули, без сборщика)
  app/                запуск, навигация, общий NetworkService
  core/               HTTP, кэш (память + IndexedDB), состояние сети, хранилище пользователя
  domain/             те же правила, что на ПК
  services/           источники серий, Shikimori
  components/         карточка, серия, меню, состояния экрана, иконки, вкладки
  features/           плеер, обсуждение, поиск, рекомендации, Shikimori, документы
  pages/              экраны
tests/                тесты ПК-версии (pytest)
mobile/tests/         тесты планшетной версии (node:test)
```

**Тесты.** ПК: `pip install -r requirements.txt pytest`, затем `python -m pytest` (Qt запускается без окна).
Планшет: в `mobile/` — `npm test` (Node 22+).

**Журнал.** ПК пишет `app.log` в папку данных (до 3 × 1 МБ): ошибки сети, базы, плеера.

## Где данные
`%APPDATA%\AnimeApp\AnimeApp\library.db` — SQLite-база (списки, прогресс, настройки), рядом `app.log` — журнал.
Постеры кэшируются в `%LOCALAPPDATA%\AnimeApp\AnimeApp\cache`.

## Сборка из исходников

**Windows:** `build_installer.bat` (нужны Python 3.11, `pip install -r requirements.txt pyinstaller`, Inno Setup 6) →
`installer/Output/AnimeApp-Setup-<версия>.exe`.

**Android:** в папке `mobile/` — `npm install`, затем `npx cap sync android` и `android/gradlew assembleRelease`
(нужны JDK 21 и Android SDK). Для подписи положите свой ключ в `mobile/android/animeapp-release.jks`
и `mobile/android/keystore.properties` (в git они не попадают).

Мобильная версия (`mobile/www`) — тот же функционал на HTML/JS внутри нативной оболочки Capacitor:
встроенный плеер (hls.js), озвучки AniLibria / AnimeVost / Kodik, сезоны, предстоящие серии, каталог,
рекомендации и ИИ-разбор.
